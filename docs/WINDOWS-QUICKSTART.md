# Windows 上手指南

直播搭子把 B 站直播页面和 AI 陪聊面板放在一个窗口里。自己和朋友各自安装、登录自己的 B 站账号，再选择「登录 ChatGPT」或「填写 API」，不需要浏览器扩展、商店注册或自建服务器。

当前桌面版仍在测试与打包阶段，请以 [项目 Releases](https://github.com/SCUliujiacheng/live-companion/releases) 实际附带的文件和验证说明为准。旧版扩展 ZIP 不是 Windows 桌面安装包。

## 1. 安装并登录

Windows x64 桌面构建使用以下文件名：

- `LiveCompanion-Setup-0.2.0-x64.exe`：安装版，运行安装程序，之后从桌面或开始菜单打开「直播搭子」。
- `LiveCompanion-Portable-0.2.0-x64.exe`：直接启动。设置和登录仍使用当前用户的应用数据目录，不是全部放在 EXE 旁边。

在左侧 B 站网页点击 B 站自己的登录入口，按提示登录。应用不会导入 Chrome / Edge 的账号；首次在应用内登录，之后可复用应用保存的会话。顶部「登录待确认」不是登录失败，账号状态以左侧网页为准。

程序本身免费开放；ChatGPT 账号用量和 API 费用由对应服务管理，不含无限免费调用。测试包未代码签名，Windows 可能显示发布者未知，请核对发行来源。

## 2. 打开主播房间

在顶部填数字房间号，或粘贴 `https://live.bilibili.com/房间号`，点击「打开直播间」。确认直播正在播放，能听到主播声音。

刷新、换房间和退出登录会停止当前陪聊，需要页面就绪后重新开始。

## 3. 连接 AI：登录账号或填写 API

点击右侧 **「AI 设置」**。默认选择「登录账号」，使用 ChatGPT 聊天，在本机识别主播声音。

### 方式一：登录 ChatGPT（默认）

1. 点击 **Continue with ChatGPT**，在打开的官方页面选择自己的账号并完成授权。密码不填在直播搭子里。
2. 如果界面显示「已登录，待授权用量」，点击「授权 ChatGPT 用量」继续官方授权。只有账号登录、没有模型用量权限时还不能聊天。
3. 在模型列表中选择账号可用模型，点击「测试聊天」检查真实请求。测试也会消耗账号用量；「管理用量」打开官方用量页面。
4. 点击「下载并准备识音模型」。首次下载约 80 MB，实际大小以下载内容为准；等待「已就绪」。以后复用模型缓存。声音在本机处理，只有转写文字、弹幕和聊天偏好交给 ChatGPT。

无需填写 API Key。登录授权会加密保存在当前 Windows 用户的应用数据中，之后可复用。「换个账号」重新打开官方登录；已保存多个账号时可从下拉框选择。先结束陪聊，再切换账号、模型或接入方式。

账号提供的模型、额度与授权资格以官方页面和实际返回为准。其他服务商的网页登录适配尚未实现，可先使用下方兼容 API 路线。

### 方式二：填写 API

切到「填写 API」，显示两组配置，各有地址、Key 和模型：

| 配置 | 工作 | 默认地址 | 默认模型 |
| --- | --- | --- | --- |
| 聊天模型 | 看懂上下文，生成接话 | `https://api.openai.com/v1` | `gpt-4.1-mini` |
| 声音转文字 | 将主播声音转成文字 | `https://api.openai.com/v1` | `gpt-4o-mini-transcribe` |

**使用 OpenAI：** 填好聊天 Key，再在「声音转文字」点「使用聊天服务的地址和 Key」，可复制同一个地址和 Key。转写模型不会被覆盖，仍需保留转写模型名称。

**使用其他服务：** 聊天服务须兼容 OpenAI 聊天接口，转写服务须兼容音频转写接口。只有聊天模型的服务不能自动承担转写；两组可使用不同服务商。填写服务商提供的 Base URL、Key 和模型，地址通常到 `/v1` 为止，不填完整 `/chat/completions` 路径。更换地址会清空对应 Key，请填写新服务的 Key。

两组都填好后点「保存设置」。「保存并测试聊天」会发真实短请求并产生少量 API 用量；「保存并检查转写连接」只检查认证和模型可见性，**不代表实际音频转写已经成功**。实际转写在开始陪聊后验证。

Key 默认只留在本次应用内存。需要下次直接使用时，主动勾选「在这台电脑上加密保存 API Key」；Windows 系统加密不可用时，程序拒绝持久保存。公用电脑请勿勾选。

开发时的 Codex 会话不会自动登录安装后的程序。你需要在应用中单独完成 ChatGPT 官方授权，或自行填写 API Key；不必把凭据发给开发者。

## 4. 从确认模式切换自动接话

1. 填写当前 B 站昵称，选择聊天风格。小笔记可以写主播称呼、已确认的梗和想避开的话题。
2. 保存后点设置页底部「返回陪聊」。第一次保持 **「我来确认」**，再点「开始陪聊」。
3. 检查「正在聊什么」中的转写和新弹幕。有候选回复时先读一遍，点「现在发送」，并观察左侧网页确认结果。
4. 确认实际效果后点「结束」，选择 **「自动接话」**，再点「开始陪聊」。

自动模式默认有 5 秒倒计时，可点「这句不发」取消。「暂停陪聊」暂停生成和发送，「结束」还会停止声音捕获。主播唱歌时可以打开「主播正在唱歌」。

默认最短发言间隔 45 秒，每条最多 30 字。它不是定时刷屏，模型可以选择安静；没有候选时先查看上下文和运行记录。

## 5. 运行和清理

- 最小化窗口可以继续运行，需电脑开机联网，直播持续播放。
- 睡眠、休眠、关机或断网会中断使用，恢复后检查房间、声音和状态，必要时重新开始。
- 关闭主窗口会结束陪聊并退出，不会隐藏到托盘继续发送。再次打开不会自动开始。

| 目的 | 操作 |
| --- | --- |
| 停止本次陪聊，保留设置 | 「结束」，已显示文字暂时保留供查看。 |
| 删除聊天偏好、API 和上下文 | 「清除聊天设置、API 与上下文」并确认；B 站、ChatGPT、AI 路线与模型缓存保留。 |
| 断开当前 ChatGPT 账号 | AI 设置中「断开 ChatGPT」并确认；多个已保存账号需分别选择并断开。 |
| 退出程序内 B 站账号 | 顶部「退出 B 站」并确认；AI 设置保留，外部浏览器不受影响。 |
| 分享给朋友 | 只分享构建的 EXE，由朋友自己登录或填 Key，不分享个人应用数据目录。 |

数据位于应用 `userData`，Windows 通常是 `%APPDATA%\直播搭子\`。普通设置与可选加密 Key 在 `settings.json`，AI 路线在 `ai-settings.json`，ChatGPT 凭据和识音缓存在各自子目录。便携版也使用用户目录。卸载或删除 EXE 不等于清除了全部数据，需要时先清除聊天/API 数据、分别断开 ChatGPT 账号并退出 B 站；识音模型缓存仍保留。详见 [隐私说明](../PRIVACY.md)。

## 常见情况

| 现象 | 检查方法 |
| --- | --- |
| ChatGPT 已登录但不能聊天 | 点击「授权 ChatGPT 用量」，检查账号可用模型和额度。 |
| 官方登录页打开后一直等待 | 在系统浏览器完成授权并返回应用；不继续登录时点「取消登录」。 |
| 识音模型下载失败 | 检查网络后点「重试准备识音模型」；已缓存模型可再次加载。 |
| 没有主播转写 | 确认数字直播间正在播放且有声音；账号路线检查本地识音状态，API 路线检查转写服务。 |
| 聊天通过测试，转写仍报错 | 两组服务分别验证，确认转写服务支持音频，不是仅支持聊天。 |
| 转写连接通过，实际转写报错 | 连接检查没有上传音频，核对转写模型、接口支持与额度。 |
| 提示输入框正在使用 | 完成或清空草稿，再让输入框失去焦点，助手不会覆盖它。 |
| 提示发送未确认 | 先看左侧是否已经发出；程序暂停以避免重复，确认后再操作。 |
| 修改 API 提示先停止 | 先点「结束」，再修改并保存。 |
| 设置损坏或密钥无法解密 | 在设置中清除本机设置后重新填写，不直接复制其他 Windows 用户的设置文件。 |

当前联调使用本地模拟 AI。ChatGPT 官方登录后的真实调用、实际模型效果、真实 OpenAI API 转写和桌面真实 B 站发言尚未完整验证；具体测试结果以该版发布说明为准。反馈请提供版本、脱敏错误和复现步骤，不提交 Key、令牌、Cookies 或私密聊天记录。
