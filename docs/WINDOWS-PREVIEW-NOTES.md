## 本次修复与云端验证

- 修复 ChatGPT 动态 client ID 在换取一次性授权码前的持久化，以及失败重启后重用；加强账号切换、取消和刷新 scope 检查。
- 修复登录回调后模型列表未自动更新；目录失败给出提示，用户可重试；保持无 API Key 的账号路线与自填 API 路线独立。
- 回归单测、静态检查、真实 Chromium 扩展/UI/API fixture 测试。
- 真实 Electron 隔离页面音频捕获、手动发送、倒计时自动发送和暂停后不得迟发。所有发送都只进入本地模拟页面。
- 真实固定版本 CPU Whisper 中文合成音频识别、取消后下一次识别、关闭并重新加载离线缓存。
- Windows NSIS 安装、全新数据目录启动、打包内 ONNX/Whisper worker、卸载，以及便携版启动与离线识别。

具体命令、日志和截图见本 tag 对应提交的 GitHub Actions。云端合成语音与模拟页面不能代表真实主播声音、真实账号或用户设备性能。

## 尚未验证，需要你验收

- 真实 ChatGPT 登录/套餐用量授权及模型推理。
- 真实 B 站登录、不同直播间适配，以及真实弹幕发送。
- 自填服务的真实计费 API、真实直播声音识别质量、你的 Windows 音频设备与安全软件兼容性。

安装包不包含账号、令牌、API Key、个人录音或模型缓存。首次本地识音需主动下载模型。使用账号获准用量；自填 API 按服务商规则收费。

## 建议验收顺序

1. 安装并启动，先登录 B 站、打开正在直播的房间，确认能听到声音。
2. 在 AI 设置中完成官方 ChatGPT 登录和用量授权，确认模型下拉列表自动出现；主动下载识音模型。
3. 保持「我来确认」，填写自己的 B 站昵称。先测试聊天，再开始陪聊，观察转写和候选回复，核对后手动发送一条。
4. 结束后切换「自动接话」，检查倒计时、「这句不发」、暂停、结束；暂停后不得继续发送。
5. 如需 API 路线，分别填写聊天与转写配置验证。退出重开检查设置、账号与模型缓存；默认不保存 API Key。

发现问题时反馈应用版本、Windows 版本、操作步骤和去除隐私后的截图。不要上传令牌、API Key、账号目录或原始个人录音。
