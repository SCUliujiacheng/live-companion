## 详细描述（可复制）

直播搭子是放在浏览器侧边栏里的 AI 陪聊助手。打开 B 站直播间，点击扩展图标，再开始陪聊；它会结合主播声音转写和最近弹幕，为你准备简短的接话。

你可以选择两种方式：

- 我来确认：先看候选回复，由你点击发送。
- 自动接话：合适的话题才生成回复，发送前展示可取消的倒计时；随时可以暂停或结束。

为了让互动自然一些，直播搭子提供发言间隔、回复字数、聊天风格、昵称和直播间小笔记设置，并通过本地规则减少复读、回应自己的弹幕和发送过时回复。主播唱歌时可以打开「主播正在唱歌」，暂停生成和发送。网页输入框里已有内容或你正在输入时，助手不会覆盖你的文字；发送未确认时会暂停，不重复点击。

使用前需要自行填写 API Key。默认支持 OpenAI，聊天和声音转写可以分别填写兼容服务的地址、模型和密钥。扩展不附送 API 额度；API 用量及费用由所选服务商计算，服务必须兼容对应接口。

隐私说明：开始后，所选直播标签页的音频片段发送到你填写的转写服务；最近弹幕、声音转写、昵称及直播间小笔记发送到你填写的聊天服务。扩展没有开发者数据后台、广告或遥测，不请求麦克风，不读取 B 站 Cookie。密钥默认仅保存在浏览器会话中，可自愿选择本机保存；本机保存未额外加密。结束陪聊会释放音频捕获，但本次已显示的文字记录会保留到新会话重置或浏览器完整重启。设置中的「清除本机设置与密钥」可同时结束监听、清除设置和会话记录，并撤销 API 站点权限。具体内容请阅读隐私政策。

需要 Chrome 116 或更新版本，以及已播放声音的 B 站直播间页面。发送弹幕需要你自己的正常登录账号。当前是早期版本：已进行隔离 Chromium 和模拟页面测试，尚未完成真实直播间、真实 OpenAI 音频转写及实际账号发送的端到端验证。网页布局变化可能影响读取或发送；识别歌曲、区分说话人和选择接话时机也可能出现错误。建议先使用「我来确认」试用。

本项目由独立开发者维护，与哔哩哔哩或 OpenAI 没有官方隶属关系。

## 单一用途说明（Privacy practices）

用户主动选择一个 B 站直播间后，结合该标签页声音转写和新弹幕生成简短中文回复，并通过用户确认或可取消的自动模式发送，用于观众与主播之间的陪聊互动。

## 权限理由（逐项填写）

| 权限 | 与单一用途对应的理由 |
| --- | --- |
| `activeTab` | 用户点击扩展工具栏图标时选择目标直播标签页，并在用户开启陪聊后取得该标签页的音频捕获授权。 |
| `scripting` | 在选定 B 站直播页面注入安装包内的固定 `content.js`，读取新弹幕并操作原有弹幕输入框和发送按钮。不会注入下载的代码。 |
| `storage` | 保存用户填写的 API 地址、模型、昵称、风格和控制参数；使用会话存储保存默认密钥、最近上下文及运行状态；只有用户勾选时才持久保存密钥。 |
| `sidePanel` | 展示 API 设置、最近上下文、候选回复、倒计时，以及开始、暂停、取消和结束按钮。 |
| `tabCapture` | 仅在用户主动开始后捕获选定直播标签页的音频，用于声音转写；不捕获麦克风、摄像头或视频。 |
| `offscreen` | 在离屏扩展文档中使用音频相关网页 API 处理标签页音轨、分段 WAV 并继续向用户播放直播声音，支持侧边栏关闭后仍由用户控制的当前陪聊会话。 |
| `https://live.bilibili.com/*` | 访问目标直播页的新弹幕及原有发送控件，并校验发送仍在同一个数字房间页面；功能由用户主动开始。 |
| 可选 `https://*/*` | 用户可自由填写 HTTPS API Base URL，无法预先列出所有兼容服务域名。保存设置时只请求填写地址对应的站点权限；实际请求只发往已配置的聊天／转写接口，不扫描其他网站。 |
| 可选回环 HTTP 权限 | `http://localhost/*`、`http://127.0.0.1/*`、`http://[::1]/*` 用于用户自行配置的本机兼容 API。设置时按所填主机申请权限；其他 HTTP 主机不被接受。 |

商店要求权限说明与实际使用一致，并按单一用途请求权限；这些说明应随最终 manifest 一起复核。[官方隐私字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 远程代码声明

选择「不使用远程代码」。全部 JavaScript、音频处理和行为规则均随扩展安装包提供；不从 CDN 下载脚本，不使用 `eval` 或动态代码解释器。

AI API 返回的是转写文字与受限 JSON 数据，包括回复文字和接话建议字段。扩展解析并验证这些数据，发送与否仍由安装包内固定规则、会话状态和用户控制决定。返回内容不会作为 JavaScript、HTML、WebAssembly 或任意命令执行。[Manifest V3 官方要求](https://developer.chrome.com/docs/webstore/program-policies/mv3-requirements)

## 数据披露填报依据

不能填写「不处理用户数据」：即使没有开发者服务器，扩展仍会把音频与对话发送给用户指定的第三方 API。最终后台选项须按当时定义逐项填写，并与隐私政策一致。

| 需要披露的实际数据 | 对应后台类别的核对依据 |
| --- | --- |
| 标签页声音、转写、弹幕和小笔记 | 网站内容；其中的聊天消息也涉及个人通信 |
| 观众昵称及用户填写的昵称 | 可识别用户的信息；不得因昵称不是实名就忽略披露 |
| API Key | 身份验证信息 |
| 所选直播间房间标识和标题 | 所选页面信息，仅在本机用于定位与显示；若后台把此类数据归入浏览活动，也应据实披露其有限范围 |

没有广告数据、支付卡信息、浏览历史数据库读取、键盘记录或跨站跟踪。公开资料中不得宣称第三方服务零保存、零训练，也不得用“完全离线”描述本扩展。
