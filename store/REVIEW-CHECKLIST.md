## 提交前功能复验

以下检查使用将要上传的同一个 ZIP 解压目录，保存测试结果与版本号；涉及真实发送时只在授权的测试场景中操作。

- [ ] 运行 `npm test`、`npm run check` 和 `npm run package`；重新执行隔离 Chromium 加载及设置测试。记录实际通过、跳过和未执行项。
- [ ] 在 Chrome 中加载最终包，确认工具栏图标、侧边栏和设置页均正常，无扩展错误。
- [ ] 验证默认 OpenAI 配置和一个自定义兼容地址；只向所填服务请求权限和传输对应密钥。
- [ ] 验证 HTTPS 与本机回环 HTTP 可用，远程明文 HTTP、带账号密码或查询密钥的 URL 被拒绝。
- [ ] 用实际音频验证转写，再验证真实聊天输出。「检查转写连接」仅检查模型列表，不得记录为转写成功。
- [ ] 核对最近弹幕和声音上下文，昵称、时间与本人回声处理正确；自己的弹幕或主播读弹幕不产生明显循环。
- [ ] 在「我来确认」模式验证倒计时不会自动发送；自动模式仅在本次用户主动选择并开始后运行。
- [ ] 验证暂停、取消、唱歌开关和结束会作废待发内容；在输入框已占用、发出前等待、API 在途及房间切换时分别测试。
- [ ] 验证账号未登录、接口失效、额度不足、音频断开和发送未确认时会显示可理解的结果，不反复发送。
- [ ] 验证关闭侧边栏不会被误认为已结束；「结束」释放标签页捕获，完整重启浏览器后不会自动继续陪聊。

- [ ] 确认描述了真实保留行为：结束不会立即删除会话文字；默认密钥和状态属于浏览器会话存储；普通设置及主动保存的密钥持久保留。
- [ ] 验证取消本机保存并保存设置会删掉持久密钥；清空两组 Key 并保存会清除会话密钥。检查最终 ZIP、截图、测试产物和 git 历史没有真实凭据。
- [ ] 验证「清除本机设置与密钥」先结束监听，清除本地与会话中的设置、密钥、上下文、运行记录和房间状态，并撤销 API 地址的可选权限；页面同步显示重置后的状态。
- [ ] 扩展中没有遥测、开发者代理、广告或无关第三方请求；不声称用户选择的任意 API 服务都零保存或零训练。
- [ ] 确认仅执行包内代码，AI 文字／JSON 只作为数据处理；所有权限都有用户可见功能理由。[Manifest V3 官方要求](https://developer.chrome.com/docs/webstore/program-policies/mv3-requirements)
- [ ] 复核有限使用声明是否符合最终数据处理安排，再由发布者完成后台认证；不能把“有隐私政策文件”当成审核已经通过。[官方 Limited Use 政策](https://developer.chrome.com/docs/webstore/program-policies/limited-use)

## 私密审核说明应包含的内容

以下是应填写的内容范围，不包含可用凭据。发布者应在提交前把具体可执行步骤和私密测试安排补充到审核后台。

1. 安装扩展后打开已提供的测试直播间，播放声音，点击工具栏图标。
2. 在 API 设置中使用通过私密渠道安排的测试服务、模型和凭据；保存并授予对应站点权限。API 配置为用户必填，安装包不含公共共享密钥。
3. 先运行聊天测试；说明转写连接检查仅查询模型列表。选择「我来确认」，点击「开始陪聊」，通过真实音频等待声音转写与候选回复出现。
4. 在测试直播场景中检查一次人工发送、一次可取消的自动倒计时，以及暂停、结束和输入框占用保护。
5. 向审核人员说明直播时段或网络条件，以及怎样联系发布者取得新的测试窗口。不能要求审核人员从公开源码自行寻找密钥，也不要将只有模拟数据的页面描述为真实端到端运行证明。

当前尚未确认真实直播间发送、实际 OpenAI 转写和模型互动质量；这些待验证项应在提交前完成，并根据结果修订商店说明。
